    Section Partial Orders and Partially Ordered Sets

    We will be discussing partial orders on a set \(A\) in this document. Both words in “partial order” are important in this type of relation. The word “order” means that the relation (to some extent) tells us how to put the elements of \(A\) in order, and the word “partial” means that we may not be able to put the elements completely in order from first to last.
    🔗
    Let’s start with a set that is both familiar and completely in order, namely the set of real numbers \(\mathbb{R}\text{.}\) To tell what order the numbers are in, we merely need the relation to tell us which numbers come before which other numbers. The relation that does that is \(\le\text{.}\) So for \(a,b \in \mathbb{R}\text{,}\) \(a \le b\) means that \(a\) comes before \(b\text{.}\) To extend the notion of order to other ordered sets, we take a look at some of the properties of \(\le\text{.}\)
    🔗
    A natural place to look is at the properties we had for equivalence relations. Let’s see if any of them work on \(\le\text{.}\)
    • Reflexive Property: If \(a \in \mathbb{R}\text{,}\) we have \(a \le a\text{,}\) and so \(\le\) is reflexive.
      🔗
      🔗
    • Symmetric Property: If \(a \le b\text{,}\) then it is very unlikely that we also have \(b \le a\text{.}\) In fact, the only way we can have both \(a \le b\) and \(b \le a\) if if \(a=b\text{.}\) So \(\le\) is as far away from being symmetric as a reflexive relation can be.
      🔗
      🔗
    • Transitive Property: If \(a \le b\) and \(b \le c\text{,}\) then it is clear that \(a \le c\text{,}\) so the transitive property works.
      🔗
      🔗
    🔗
    So it looks like we almost have the properties we need to define partial orders. We just have to figure out to do with that property that seems to be hostile toward symmetry.
    🔗

    Definition 50.

    Let \(A\) be a set, and let \(R\) be a relation on \(A\text{.}\) We say that \(R\) is antisymmetric if whenever we have both \(aRb\) and \(bRa\text{,}\) then it follows that \(a=b\text{.}\)
    🔗
    🔗
    This leads us to the definition of partial orders and partially ordered sets.
    🔗

    Definition 51.

    Let \(A\) be a set.
    • A relation \(R\) on \(A\) is a partial order if \(R\) has the reflexive property, the antisymmetric property, and the transitive property.
      🔗
      🔗
    • If \(>A\) has a partial order \(R\) on it, we call \(A\) a partially ordered set, which is often called a poset.
      🔗
      🔗
    🔗
    🔗
    Before we look at some examples, we should look at another property of the \(\le\) relation on real numbers. If we have two real numbers \(a\) and \(b\text{,}\) we know one of three things: Either \(a\) is smaller than \(b\text{,}\) \(a\) is bigger than \(b\text{,}\) or \(a\) is equal to \(b\text{.}\) We can summarize this by saying that either \(a \le b\) or \(b \le a\text{.}\) This leads us to the definition of a connex relation.
    🔗

    Definition 52.

    A relation \(R\) on a set \(A\) is connex if for all \(a, b \in A\text{,}\) we either have \(aRb\) or \(bRa\text{.}\)
    🔗
    🔗
    If we add the connex property to the list of partial order properties, we get what is called a total order.
    🔗

    Definition 53.

    A relation \(R\) on a set \(A\) is a total order if it satisfies the reflexive property, the antisymmetric property, the transitive property, and the connex property. In other words, a total order is a partial order that also satisfies the connex property.
    🔗
    🔗
    So \(\le\) is a total order on the set \(\mathbb{R}\text{.}\) Let’s look at a partial order that is not a total order.
    🔗

    Example 54.

    Let \(S\) be a set, and let \(A=\mathcal{P}(S)\text{,}\) the power set of \(S\text{.}\) In other words, \(A\) is the set of all subsets of \(S\text{.}\) Note that \(\subseteq\) is a relation on \(A\) defined as follows: For all \(X,Y \in A\) (i.e. for all \(X\) and \(Y\) that are subsets of \(S\)), \(X \subseteq Y\) means that every element of \(X\) is also an element of \(Y\text{.}\)
    🔗
    Note that if \(X \in A\text{,}\) then \(X \subseteq X\) (i.e. every subset of \(S\) is a subset of itself), and so \(\subseteq\) is reflexive. If you have that \(X \subseteq Y\) and \(Y \subseteq X\text{,}\) this is the very definition of \(X=Y\text{.}\) Thus, \(\subseteq\) is antisymmetric. Finally, if \(X \subseteq Y\) and \(Y \subseteq Z\text{,}\) that means every element of \(X\) is an element of \(Y\text{.}\) But every element of \(Y\) is an element of \(Z\text{.}\) Since all elements of \(X\) are in \(Y\text{,}\) that means that every element of \(X\) is in \(Z\text{,}\) which means \(X \subseteq Z\text{.}\) Thus, \(\subseteq\) is a partial order.
    🔗
    Note that \(\subseteq\) is not a total order. For instance, if \(A=\mathcal{P}(\mathbb{Z})\text{,}\) look at the subsets \(X=\{1,2,3,4,5\}\) and \(Y=\{6,7,8,9,10\}\text{.}\) If \(\subseteq\) were a total order, we would need to have either \(X \subseteq Y\) or \(Y \subseteq X\text{.}\) But neither of these sets is a subset of the other. This means that \(\subseteq\) is not connex, and so \(\subseteq\) is not a total order.
    🔗
    🔗
    We can think of a partial order on a set \(A\) as a relation that ranks the elements of \(A\text{.}\) In that spirit, we define the following.
    🔗

    Definition 55.

    Let \(A\) be a set with partial order \(R\text{.}\)
    • We say that \(a,b \in A\) are comparable if either \(a R b\) or \(b R a\text{.}\)
      🔗
      🔗
    • We say that \(a\) is maximum in \(A\) if \(b R a\) for all \(b \in A\text{.}\) This means that \(a\) is unambiguously the highest ranking element in the set.
      🔗
      🔗
    • We say that \(a\) is minimum in \(A\) if \(a R b\) for all \(b \in A\text{.}\) This means that \(a\) is unambiguously the lowest ranking element in the set.
      🔗
      🔗
    • We say that \(a\) is maximal in \(A\) if there are no other elements \(b\) with \(a R b\text{.}\) This means that we cannot necessarily declare \(a\) to be the highest ranking element in the set, but there is no other element that has higher rank.
      🔗
      🔗
    • We say that \(a\) is minimal in \(A\) if there are no other elements \(b\) with \(b R a\text{.}\) This means that we cannot necessarily declare \(a\) to be the lowest ranking element in the set, but there is no other element that has lower rank.
      🔗
      🔗
    🔗
    🔗
    Let’s see how these concepts play out in an example.
    🔗

    Example 56.

    Suppose \(S = \{ 1,2,3,4,5,6,7 \}\text{,}\) and let \(\subseteq\) be the relation described above on \(\mathcal{P}(S)\text{.}\) Let’s look at each of the above concepts one at a time.
    • Comparable: The subsets \(\{1,3,4\}\) and \(\{1,2,3,4,5\}\) are comparable since \(\{1,3,4\} \subseteq \{1,2,3,4,5\}\text{.}\) However, \(\{ 1,3,4\}\) and \(\{1,2,4\}\) are not comparable, since neither is a subset of the other.
      🔗
      🔗
    • Maximum: The maximum of \(\mathcal{P}(S)\) is \(S\text{.}\)
      🔗
      To prove this, we assume \(X \in \mathcal{P}(S)\) and show that \(X \subseteq S\text{.}\) Since \(\mathcal{P}(S)\) is the set of all subsets of \(S\text{,}\) we have \(X \subseteq S\text{,}\) which completes the proof.
      🔗
      🔗
    • Maximal but not Maximum: Suppose we let \(A=\mathcal{P}(S) \backslash \{S\}\text{.}\) In other words, \(A\) consists of all subsets of \(S\) except \(S\text{.}\) Then \(\{1,2,3,4,5,6\}\) is maximal but not maximum.
      🔗
      We prove it is maximal first. Then we will prove that it is not maximum. We will prove it is maximal by contradiction. Let \(X \in \mathcal{P}(S) \backslash \{S\}\text{,}\) and assume both that \(\{1,2,3,4,5,6\} \subseteq X\) and that \(X \ne \{1,2,3,4,5,6\}\text{.}\) Since \(\{1,2,3,4,5,6\}\) has six elements and is a subset of \(X\text{,}\) that implies that \(X\) has at least six elements. Since \(S\) has seven elements and \(X \subseteq S\text{,}\) that implies that \(X\) has at most seven elements. However, if \(X\) has seven elements, then it has to be \(S\text{,}\) which is a contradiction. Thus, \(X\) has six elements. But since \(\{1,2,3,4,5,6\} \subseteq X\text{,}\) then \(X\) has 1, 2, 3, 4, 5, and 6 as elements. This is six elements, so \(X=\{1,2,3,4,5,6\}\text{,}\) which is also a contradiction.
      🔗
      To prove that \(\{1,2,3,4,5,6\}\) is not maximum, notice that \(\{1,2,3,4,5,6\}\) is not a subset of \(\{7\}\text{,}\) and \(\{7\}\) is not a subset of \(\{1,2,3,4,5,6\}\text{.}\) Thus, it is not true that every element of \(\mathcal{P}(S) \backslash S\) is a subset of \(\{1,2,3,4,5,6\}\text{.}\) Thus, \(\{1,2,3,4,5,6\}\) is not maximum. This completes the proof.
      🔗
      🔗
    • Minimum: The minimum of \(\mathcal{P}(S)\) is \(\emptyset\text{.}\)
      🔗
      To prove this, we assume that \(X \in \mathcal{P}(S)\) and show that \(\emptyset \subseteq X\text{.}\) Since \(X\) is a set and \(\emptyset\) is as subset of every set, it follows that \(\emptyset \subseteq X\text{,}\) which completes the proof.
      🔗
      🔗
    • Minimal but not Minimum: Suppose we let \(A=\mathcal{P}(S) \backslash \{\emptyset\}\text{.}\) In other words, \(A\) consists of all subsets of \(S\) except \(\emptyset\text{.}\) Then \(\{7\}\) is minimal but not minimum.
      🔗
      We prove it is minimal first. Then we will prove that it is not minimum. We will prove it is minimal by contradiction. Let \(X \in \mathcal{P}(S) \backslash \{\emptyset\}\text{,}\) and assume both that \(X \subseteq \{7\}\) and that \(X \ne \{7\}\text{.}\) Since \(\{7\}\) has one element and contains \(X\text{,}\) that implies that \(X\) has at most one element. Thus, \(X\) has one element or zero elements. If \(X\) has one element, then it has to be \(\{7\}\text{,}\) which is a contradiction. Thus, \(X\) has zero elements. But that makes \(X\) the empty set, which is also a contradiction.
      🔗
      To prove that \(X\) is not minimum, notice that \(\{6\}\) is not a subset of \(\{7\}\text{,}\) and \(\{7\}\) is not a subset of \(\{6\}\text{.}\) Thus, it is not true that \(\{7\}\) is a subset of every element of \(\mathcal{P}(S) \backslash \{\emptyset\}\text{.}\) Thus \(X\) is not minimum. This completes the proof.
      🔗
      🔗
